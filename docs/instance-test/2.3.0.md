# 实例测试留档：2.3.0

> 2.3.0 是**授权与交付版本**，核心变更是三档 License、AI 客服重点交付、英文版与 installer 产物。
> 真实业务实例沿用 2.2.0 的「电商订单咨询 H5 客服」库（`gewumind_h5_ecom_test`，10 笔订单），
> 用于验证 2.3.0 对 N-1 业务库的兼容性；同时用 installer 做了全新空库安装。

## 需求

1. **三档授权**：基础版免费；标准版 `pro-2026` 除 AI 外全部；旗舰版 `ent-2026` 全部功能。
2. **AI 客服重点**：AI 会话、工具目录、AI 角色、知识库、H5 渠道在旗舰版可用；标准版不可用。
3. **中英文**：中文库 + 英文库分别启动，页面和 AI 回答无中文/英文串档。
4. **交付**：只发布 `gewumind-installer` 使用的最小应用包、数据库包、manifest 与安装器。

- 应用：`2.3.0`；内核：`0.4.2`；数据库基线：`db/releases/2.3.0/{zh,en}/full.sql`
- 全新安装库：`gewumind-install-test-230`（installer 导入，63 张表）

- License：标准版 `pro-2026`、旗舰版 `ent-2026`，均由 `gewumind-sign` v2.0.1 签发

## 踩坑

1. **中文最小包不要用 `--profile en` 启动**：installer 的中文包只包含 `data/zh`，英文 profile 会找不到
   `/system/security/login` 的 magic-api 脚本，表现为 404。语言包和 `--lang` / `--profile` 必须一致。
2. **同一台开发机的试用状态会继承**：`~/.gewumind` 的 trial state 与 `sys_configure.license.trial.startedAt`
   会让新库显示 `trial-expired`；这是按机器计时，不是 2.3.0 回归。正式客户新机器不会继承。
3. **License 三档收敛**：`ADDON` 已删除，`addon-ai-2026` 私钥/公钥/DB 行已移除；内核 keyring 不再包含它。
4. **旧 2.x License**：2.2.0 的 `legacy-0.4.0` 仍可验签；新签发统一用 `pro-2026` / `ent-2026`。
5. **发布包必须停实例再打包**：fat jar 运行中覆盖会 404；本次先停 9080/9081 再 `build-dist.sh`。仅复用已构建 jar 的 `--skip-build` 不覆盖运行中文件，已允许在实例运行时执行。
6. **前端已迁出**：本版前端源码在独立仓库；内核构建用
   `mvn -Dfrontend.dir=/path/to/frontend package`，应用壳 `src/main/resources/static/`
   需要同步新 `dist/`，否则会命中旧的 8 个 hash 不匹配资源。
7. **不要再预置开发 Key**：英文 `full.sql` 曾有 `dev-local` 种子，已删除；开发 Key 统一由
   `ai.dev-access.enabled` 打开后生成，避免发行库自带可用凭证。

## 结论

2.3.0 三档授权、AI 客服、AI 开发接入、中英文与 installer 交付均通过；可发布。
