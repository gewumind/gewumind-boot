# GewuMind Boot 2.3.0

2.3.0 是 **AI 客服与授权交付版本**。

## 重点

- **AI 客服（旗舰版）**：可信 AI 问答、只读工具目录、AI 角色与数据范围、知识库、对外 H5 客服。
  模型不直接访问数据库；答案来自授权工具，服务端做权限、脱敏与逐项校验。
- **三档授权**：
  - 基础版：核心平台功能，免费；
  - 标准版 `pro-2026`：除 AI 外全部商业能力；
  - 旗舰版 `ent-2026`：全部能力，含 AI。
- **中英文**：`data/{zh,en}/magic-api` 与独立语言库；AI 回答、菜单、工作流、报表均中英文可用。
- **数据库基线**：统一使用 `db/releases/2.3.0/{zh,en}/full.sql`。
- **安装器交付**：Release 只发布 installer 所需的最小应用包、数据库包、manifest 与跨平台安装器。

## 升级说明

2.3.0 是新的数据库基线，没有 `upgrade-from-*.sql`。旧库请按升级说明迁移或新建库后导入
`db/releases/2.3.0/<lang>/full.sql`。

2.2.0 的业务库可继续由 2.3.0 启动，`legacy-0.4.0` 授权仍兼容；新授权统一使用 `pro-2026` / `ent-2026`。

## 验证

- 标准版只启用 9 项非 AI 能力；旗舰版 12 项全部启用。
- AI 数据问答返回真实订单数据，中英文均通过。
- installer 全新空库安装 63 张表；2.2.0 H5 业务库在 2.3.0 下登录、H5 渠道与订单数据正常。
- 详见 `docs/instance-test/2.3.0.md`。
