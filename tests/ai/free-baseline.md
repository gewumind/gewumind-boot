# 1.x 免费功能基线（2.x/3.x 回归清单）

> 原则：**1.x 原本免费的功能，在 2.x/3.x 继续免费**——不加 License 门禁、不改变开关与权限、不降级。
> 2.x/3.x 的 License 只解锁**新增**能力（AI 客服 / 知识库 / 智能体开发）。
> 每个版本发布前必须跑通本清单，确保菜单、接口、页面、权限与 1.x 一致。

## 2. 既有商业能力（授权行为不变，不因 2.x 升级改变）

SSO、工作流、Redis、MQTT、Kafka、WS、SSE、TCP、模块管理——沿用 1.x 的 License 策略：
有授权按授权生效，无授权不注册模块、保留数据、页面告警，**不锁死系统其他功能**。

## 3. 三态门禁边界（2.0 新增 AI 客服）

| 状态 | AI 客服（trusted-chat） | 1.x 免费功能 | 1.x 商业能力 |
|---|---|---|---|
| 无 License + 试用期内（TRIAL） | 可用（试用全放开） | 正常 | 正常 |
| 无 License + 试用过期（TRIAL_EXPIRED） | 入口升级提示；`/api/ai/chat/stream` 返回 `AI_DISABLED`，不泄露数据 | 正常 | 按 1.x 策略 |
| 有 License + `ai.enabled=false` | 不启用（配置中心关闭） | 正常 | 正常 |
| 有 License + `ai.enabled=true` | 可用 | 正常 | 正常 |
| License 过期/无效/验签失败 | 同 TRIAL_EXPIRED；验签失败记审计，不得降级为可用 | 正常 | 按 1.x 策略 |

**验收要点：**

1. 未登录直接调 `/api/ai/chat/stream` → 错误事件（`AI_DISABLED` 或 401），不得返回任何业务数据。
2. `ai.enabled=false` 时调用 → `AI_DISABLED`；恢复 `true` 后立即可用（无需重启）。
3. 门禁关闭/未授权时，`/api/ai/data/query`（1.x 免费数据问答）与上表免费模块**不受影响**。
4. 授权到期后：AI 会话历史/工具目录/审计数据**保留不删**，重新导入有效授权即恢复。
